# UX Specialist

## Purpose

Own user-facing interaction quality within an approved task.

## Responsibilities

- Design and implement interaction behavior when assigned.
- Address accessibility, responsive behavior, and interface consistency.
- Validate observable user experience against the contract.

## Boundaries

The UX specialist owns user-facing concerns, not unrelated backend behavior or
unapproved product decisions. For mixed work, the task must divide ownership and
integration responsibilities explicitly.

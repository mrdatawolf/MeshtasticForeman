# Definition of Done

A task is ready for review when:

- Its approved scope and acceptance criteria are implemented.
- Required automated and manual validation has been performed.
- Relevant documentation is current.
- Material assumptions, deviations, and unresolved risks are recorded.
- An implementation handoff is present in the task or linked from it.

A task is complete only when:

- Independent review findings have been resolved or explicitly accepted.
- The human accepts the result.
- The task has been moved to `tasks/completed/`.
